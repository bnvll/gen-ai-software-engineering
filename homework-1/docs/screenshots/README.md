# Screenshots

`TASKS.md` asks for three screenshots. These are them — nothing else is needed.

| File | TASKS.md item | What must be visible |
|---|---|---|
| `ai-prompt.png` | *Screenshots of AI tool interactions showing prompts and generated code* | The Claude Code panel with the prompt legible **and** the code it produced — e.g. the request to cover the untested "overdrawn account accrues negative interest" claim, next to the two new tests in `tests/accounts.test.js`. The tool and model (`Opus 5`) should be identifiable. |
| `api-running.png` | *Screenshot of your API running successfully* | Two terminals side by side: the left running `./demo/run.sh`, showing the startup banner (`seeded 10 transactions`, `listening on http://localhost:…`, `rate limit: 100 requests / 60s per IP`) followed by request log lines; the right firing the requests that produced them, with a mix of `200`, `201`, `400` and `404`. |
| `postman-requests.png` | *Screenshot of sample API requests/responses (using Postman, curl, or similar)* | A Postman request and its response — ideally **Create a transfer → 201** with the JSON body and its passing test, or **Every field invalid at once → 400** showing all four `details[]` entries. Collection: `demo/postman-collection.json`, see [`../api-client-guide.md`](../api-client-guide.md). |

Embed all three in the pull request body as well — the repo rules reject
submissions whose PR has no images. Placeholders are ready in
[`../PULL_REQUEST.md`](../PULL_REQUEST.md).

## Reproducing them

```bash
./demo/run.sh                 # api-running.png (add --port 3456 if 3000 is busy)
npm test                      # 77 tests, if you want a test-run image too
```

Text transcripts of a full run — startup log, 31 requests with responses, and
the test output — are generated by `./demo/capture-evidence.sh` into
[`../evidence/`](../evidence/), so the screenshots do not have to carry every
detail on their own.

## Before attaching

- Check each image for your work email, tokens, or unrelated repository names.
- Use a readable font size (14–16 px) — GitHub scales images down.
- Widen the terminal until log lines stop wrapping.
